## Overview

This repository demonstrates basic SQL usage and relational database concepts from an operational DevOps perspective.  
It focuses on writing and understanding queries used for troubleshooting, validation, and data inspection rather than database design or optimization.

### What this project demonstrates
- Basic SQL querying (SELECT, WHERE, JOIN, GROUP BY)
- Understanding relational data structures
- Reading and validating data stored in relational databases
- Practical database interaction skills useful for DevOps and cloud operations

### How this is used in DevOps work
- Assisting with deployment validation and data checks
- Supporting application troubleshooting involving databases
- Understanding how applications interact with relational data stores

### Notes
This repository is intentionally scoped to fundamentals and does not cover database schema design, performance tuning, or advanced SQL features.
